# Support

Use the following channel:

- reproducible defects: GitHub bug report;
- bounded feature proposals: GitHub feature request;
- usage and interpretation questions: GitHub Discussions;
- vulnerabilities: private reporting in [SECURITY.md](SECURITY.md);
- conduct concerns: contact the repository owner privately.

Before asking for help, collect:

```bash
hopwhy --version
hopwhy --format json capabilities
hopwhy --format json inspect TARGET --dry-run
```

Share the smallest report needed. Keep query values and addresses redacted,
omit body samples, and remove environment-specific data that is not relevant.
Do not post credentials, private keys, session tokens, private certificates, or
unreviewed internal topology.

Best-effort community support does not carry an uptime or response-time SLA.
